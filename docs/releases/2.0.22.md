# InfinityExpansion2 v2.0.22 — read-only historical item PDC type provenance

Distinct successor to the immutable official [v2.0.21](https://github.com/wickidcow/SF_InfinityExpansion2/releases/tag/v2.0.21), carrying the diagnostic-only changes from [merged PR #85](https://github.com/wickidcow/SF_InfinityExpansion2/pull/85).

## What changed

- `/ie2 doctor compare` now distinguishes a **PDC key stored under different primitive types** in the two real held items (or their currently registered Slimefun/GEO templates). Previously, matching PDC key names could coexist with different stored types without a specific diagnostic.
- Read-only evidence reports bounded **key names and TYPE/TYPE labels only**, e.g. `addon:owner (STRING/LONG)`; it never reads, prints, changes, or coerces persistent owner IDs, ledger values, storage records, item lore, or original quantities.
- Supports primitive byte, short, integer, long, float, double, string, byte-array, integer-array, and long-array labels, conservatively reporting unrecognized/adapter types as `OTHER`.
- Maintains the existing bounded redacted Adventure name/lore shape reporting, three-line source evidence, strict full `ItemStack.isSimilar` comparison, registered Slimefun/GEO source evidence, and original historical item preservation.

## Tests and release gates

- Four new MockBukkit regressions compare representative old/new stacks with the same Slimefun ID but differently typed owner or ledger PDC, distinguish changed values with unchanged type from true type changes, detect one-sided missing keys, verify value redaction and preserve original native ItemStack serialized byte arrays.
- Existing native Paper regressions exercise genuine registered `SMALL_URANIUM` cheat template versus GEO template, real `GeoQuarry.process` and `BlockMenu.pushItem`, inventory stacking, world item entities, stored-storage data and clean restart preservation. **These fresh producer tests do not prove historical AlbionMC old items stack.**
- Require exact-source full Gradle build, six migration/Doctor/mob-simulation/transport source checks, candidate core compatibility, native Paper 1.21.11, 26.2 and 26.3 two-boot tests, Java 21 raw plugin JAR and release asset provenance before publication. Publish only from successful validated current master source to a new immutable `v2.0.22` tag with canonical `SF_InfinityExpansion2.0.22.jar`.

## Compatibility and unresolved historical cases

This is **diagnostic-only**. Existing saved Chinese storage/machine presentations, original AlbionMC `SMALL_URANIUM`, old QuickShop-Hikari shop templates, physical Cargo, Fluffy Barrel stock, typed PDC, ownership, block/inventory storage, and amounts are not repaired or rewritten. Real original AlbionMC historical serialized bytes are still needed to prove their exact mismatch before any source-specific compatibility fix. `/ie2 doctor compare` is read-only and requires a player to hold the two actual source items in main/offhand; review redacted output, not private stack data.
