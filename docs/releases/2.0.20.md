# InfinityExpansion2 2.0.20 — read-only historical GEO provenance diagnostics

**Distinct successor to immutable v2.0.19.** Publish only from a verified current master commit after full Gradle, six source-safety checks, native Paper 1.21.11 / 26.2 / 26.3 tests and exact raw-JAR provenance verification. Do not replace prior tags or assets.

## Changes

- Extend the read-only `/ie2 doctor compare` diagnostic to distinguish the registered Slimefun item template, registered GEO resource template, real GEO Quarry output, and `/sf cheat` held items.
- Report bounded, redacted Adventure component shape and serialized field-name differences to help locate source-specific presentation changes without exposing private PDC values.
- Add MockBukkit regression coverage for redaction, non-mutation and bounded diagnostic output.

## Important compatibility boundaries

This release **does not repair historical item stacking**. Older `SMALL_URANIUM` and other persisted items can still have different Adventure name/lore structures despite identical Slimefun IDs. Do not assume this release resolves old QuickShop-Hikari shops or historical storage contents. The Doctor comparison is diagnostic only; it does not rewrite stored items, typed PDC, owner metadata or quantities.

The follow-up source fix is tracked in [issue #82](https://github.com/wickidcow/SF_InfinityExpansion2/issues/82), coordinated with [Slimefun Legacy core issue #615](https://github.com/wickidcow/Slimefun-Legacy/issues/615).
