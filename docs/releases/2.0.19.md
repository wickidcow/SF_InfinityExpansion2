# InfinityExpansion2 2.0.19 — Cargo compatibility and opt-in historical presentation Doctor

**Distinct successor to immutable v2.0.18.** Publication is source-pinned, gated by successful exact-master CI, native Paper fixtures and raw JAR verification. Do not overwrite old tags or assets.

## Included fixes

- Cargo now accepts Slimefun's immutable `ItemStackWrapper` during IE2 Storage Unit identity checks without calling its unsupported `clone()`; PDC, names, custom models, item IDs and stored quantities still fail closed on mismatch ([#76](https://github.com/wickidcow/SF_InfinityExpansion2/pull/76)).
- Preserves upstream conflict evidence without automatically adopting incompatible source changes ([#77](https://github.com/wickidcow/SF_InfinityExpansion2/pull/77)).
- Adds the reviewed opt-in historical Chinese-to-English presentation Doctor ([#74](https://github.com/wickidcow/SF_InfinityExpansion2/pull/74)). Name-only items and filled IE2 Storage Units are eligible only when Chinese text precisely matches bundled translations and typed saved storage ledger data; unknown/custom texts are refused.
- Repairs act **only on the exact held main-hand item after explicit operator preview, token confirmation and durable verified original-byte backup**. Rollback is receipt-scoped, validates the current candidate, and works across restart. Original typed PDC, nested inventory identity and item amount must not change. Strict native byte round-trips reject loss of opaque components.

## Configuration and operational boundary

`doctor.historical-presentation-repair: false` remains the default. Version 2.0.19 **does not automatically translate, migrate, or rewrite** any old item, block, barrel, Cargo inventory, offline player data or database. Keep historical presentation repair disabled on live worlds until a backed-up staging clone validates the specific owner items. Read-only diagnostics and normal machine activity remain available.

To test an original saved Chinese item on a private clone, follow [the Doctor instructions](../DOCTOR_HISTORICAL_PRESENTATION.md), including `/ie2 doctor presentation preview`, explicit confirmation, a clean server restart and receipt rollback. Never test item conversion on a production player inventory. Keep the original backups.
